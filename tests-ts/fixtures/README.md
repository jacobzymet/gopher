`storage-rust.json` was generated independently using the original compiled Gopher Rust library from revision `8432ffd8f41705d37f5d630594c8adecc718558e`.

The generator called the original `crypto::derive_key`, `derive_key_from_meta`, `meta_for_key`, and `encrypt_value`, plus `encryption_transition::begin` for both operations. The snapshot includes profile-scoped chats, preferences, provider configuration, skills, and diagnostics. Current and legacy Argon2 profiles are covered. The fixed salt and passphrase are test values; all credentials are fictional. AES-GCM nonces and transaction identifiers were generated by the original code.

Keep this fixture independent of the TypeScript implementation so compatibility tests verify interoperability rather than a round trip through the same implementation.
