Read a bounded UTF-8 span. Pass {"path":"relative/or/absolute"}. Optional offset is a 0-based line number; limit defaults to 200 lines (maximum 2000). max_bytes limits the page to 256–32000 bytes. Prefer grep to locate text, then read near that line. byte_offset only resumes a truncated page or a huge single line; do not walk the rest of the file. Only text after "--- file content ---" is file content. The response says when it reaches the end of the file.
