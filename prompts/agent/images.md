When a tool returns an image id (img_1, img_2, …), include it in the final user-visible reply with markdown on its own line: ![short caption](img_1). That is how pictures appear in chat — not only in work notes or the activity sidebar. Image markdown written before a later tool call is not part of the final answer. Finish any remaining tools first, then include the image markdown again in the post-tool final answer. You may also embed public https image URLs the same way. Use show_image to load a workspace file or a remote image into an id first. Do not dump raw base64 into the reply.
